# 🧪 Маленькая Лаборатория — v1.1

Idle-симулятор лаборатории для Yandex Games. В v1.1 основной игровой цикл перенесён на исследования и эксперименты.

## Что нового

- 📦 склад с ограниченной вместимостью;
- 🧪 экспериментальный стол с риском аварии и неизвестными открытиями;
- 🧬 скрытые рецепты, которые открываются через эксперименты;
- 🏪 лабораторный рынок с покупкой редких элементов и продажей созданных предметов;
- 📺 добровольные rewarded-рекламы для бонусов, расширения склада и x2 продажи;
- ⚡ проект №001 — сборка лабораторного существа из редких деталей;
- 📖 расширенная энциклопедия открытий;
- 🔬 технологии теперь открывают новые механики;
- 💾 более безопасная нормализация сохранения и выбор более свежего cloud/local состояния;
- 🚫 рекламные награды не выдаются при отсутствии Yandex Games SDK.

## Основной цикл

Производство → склад → эксперимент → открытие → создание/продажа → редкие детали → проект №001 → новые исследования.

## Запуск локально

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000/`.

## Yandex Games

SDK подключён только с официального адреса Yandex Games. Рекламные бонусы выдаются после callback `onRewarded`.

Перед публикацией необходимо отдельно проверить игру в окружении Yandex Games: рекламу, cloud save, мобильный интерфейс, фокус/звук и модерационные требования.

## CI

`.github/workflows/ci.yml` проверяет структуру проекта, manifest, HTML/SDK, синтаксис JavaScript, локальные URL и собирает ZIP-артефакт.
