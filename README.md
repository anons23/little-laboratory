# 🧪 Маленькая Лаборатория — v1.0

Idle-симулятор лаборатории для Yandex Games.

## Возможности

- idle-производство и офлайн-доход;
- ресурсы и рецепты с настоящими запасами;
- машины и учёные;
- дерево технологий;
- случайные события;
- престиж;
- коллекция открытий;
- локальное и облачное сохранение через Yandex Games SDK;
- rewarded video и fullscreen-реклама только через Yandex Games SDK;
- адаптивный интерфейс для мобильных устройств.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## CI

GitHub Actions проверяет структуру проекта, manifest, HTML/SDK, JavaScript-синтаксис, потенциально опасные URL и собирает ZIP-архив игры как artifact.

## Публикация

Для публикации загрузите ZIP из artifact в Консоль разработчика Yandex Games и включите монетизацию средствами SDK.
